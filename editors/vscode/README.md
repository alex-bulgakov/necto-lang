# Necto Language Extension for Visual Studio Code

Официальное расширение поддержки языка программирования **Necto** (`.nc`) для VS Code и Cursor.

## Возможности
- 🎨 **Подсветка синтаксиса:** ключевые слова, типы, интерполированные f-строки `f"..."`, Tagged Enums, операторы и комментарии.
- ⚡ **Сниппеты:** быстрые шаблоны для `fn`, `struct`, `impl`, `enum`, `match`, `test`.
- 🔲 **Автозакрытие и соответствие скобок:** `{ }`, `[ ]`, `( )`, кавычки.
- 💬 **Комментарии:** переключение строчных (`//`) и блочных (`/* */`) комментариев.

## Установка вручную
1. Скопируйте папку `editors/vscode` в директорию расширений VS Code:
   * **Windows:** `%USERPROFILE%\.vscode\extensions\necto-language`
   * **Linux / macOS:** `~/.vscode/extensions/necto-language`
2. Перезапустите или обновите окно VS Code (`Developer: Reload Window`).
